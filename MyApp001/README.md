# MyApp001 – Hádání čísla

Úkol 002 – první aplikace v Android Studiu (XML layout + `findViewById`).

- Aplikace si myslí náhodné číslo od 1 do 100.
- Uživatel zadává tipy a aplikace odpovídá **PŘIDEJ** (číslo je větší) nebo **UBER** (číslo je menší); barva textu se mění podle výsledku.
- Počítá se počet pokusů, neplatný vstup se ošetří hláškou.
- Po uhodnutí se tlačítko změní na **Hrát znovu** a hra začne od začátku.
- Po odeslání tipu se schová klávesnice.
