# PMA 2026

Repozitář s úkoly z předmětu Programování mobilních aplikací – Ondřej Bím.

## 1. cvičení (24. 9. 2026)

- **Úkol 001:** založení repozitáře.
- **Úkol 002:** příprava Android Studia a první aplikace [MyApp001](MyApp001) – hra na hádání čísla 1–100 (rady PŘIDEJ / UBER, počet pokusů, nová hra).

## 2. cvičení (1. 10. 2026)

- **Úkol 003:** Hoď kostkou ve dvou verzích:
  - [MyApp003Xml](MyApp003Xml) – XML layout + `findViewById`,
  - [MyApp003Compose](MyApp003Compose) – Jetpack Compose.
  - **Vlastní vylepšení (obě verze):** statistika hodů (počty stěn ⚀–⚅, průměr, vynulování) a zlatě zvýrazněná šestka.
  - **Porovnání:** v XML kód ručně přepisuje text a barvu `TextView`; v Compose se mění jen stav a UI se překreslí samo. Podrobněji v README obou složek.

## 3. cvičení (8. 10. 2026)

- **Úkol 004:** [MyApp004Objednavka](MyApp004Objednavka) – objednávka bot (Nike, Adidas, Hoka), XML layout (LinearLayout) + View Binding.
  - RadioButtony mění obrázek boty, CheckBoxy upřesňují konfiguraci, tlačítko **Objednat** vypíše souhrn objednávky.
  - Zadání: https://github.com/zizanek/github-tz-pma-2026/issues/4
